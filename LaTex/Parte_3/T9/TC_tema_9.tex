\begin{frame}{Sistemas trifásicos}
\begin{block}{Algunas observaciones...}
\begin{itemize}
	\justifying
  \item Los sistemas trifásicos se utilizan en la generación, transporte y distribución de energía eléctrica.
  \item Las instalaciones domésticas y/o de pequeña potencia son monofásicas, a partir de una derivación del sistema trifásico.
\end{itemize}
\end{block}

\begin{block}{Ventajas de los sistemas trifásicos}
\begin{enumerate}
	\justifying
  \item Para una misma potencia y tensión, el sistema trifásico (tres fuentes) es más económico que el monofásico (una fuente).
  \item La potencia instantánea es constante en una alimentación trifásica. 
  \item Ventajas en las máquinas eléctricas rotativas (por ejemplo, menos vibraciones). 
\end{enumerate}
\end{block}

\end{frame}
